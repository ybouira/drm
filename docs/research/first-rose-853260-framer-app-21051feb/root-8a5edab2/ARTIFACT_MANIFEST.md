## Known gaps

- **Hero background video — genuinely unrecoverable.** The hero contains a `<video>`
  element (`loop`, muted, playsinline, **`autoplay: false`**) inside an absolutely
  positioned `z-index: 0` layer, but it has **no source**: the `src` attribute is empty
  (so `video.src` resolves to the page URL), `currentSrc` is `""`, and there are zero
  `<source>` children. There is nothing to download. The live site therefore renders the
  hero as a flat `#0d0d0f` panel with a bottom gradient, and the clone matches that.
  **No generated substitute was used** — the optional Atlas Cloud fallback was not
  invoked, and no user approval for one was sought.

- **Per-width responsive layouts were not visually confirmed.** `resize_window` reported
  success but the viewport stayed pinned at 1707×945 (dpr 1.5) for every requested size,
  so tablet/mobile renderings could not be observed. Breakpoints were instead read exactly
  from the site's own CSSOM (`≥1440` / `810–1439` / `≤809`), and each spec's responsive
  section states which parts are measured versus inferred. The desktop layer is measured;
  the smaller tiers are reasoned from those breakpoints.
